# SunGang XP · 个人网站

一个仿照 **Windows XP 桌面**打造的个人网站 / 博客。纯 HTML + CSS + 原生 JavaScript，零依赖、无需构建，所有图标和壁纸都是手绘 SVG。

## 功能

- **完整的开机流程**：开机画面 → 欢迎屏幕（点击用户名登录）→ 桌面；还有注销、待机、关机、重新启动
- **窗口管理器**：拖动、八向缩放、最大化/最小化（带飞入任务栏动画）、双击标题栏、层叠与激活状态、任务栏按钮
- **开始菜单**：Luna 风格双栏菜单 + “所有程序”子菜单
- **桌面**：图标单击选中 / 双击打开、框选、右键菜单、通知区域时钟和气球提示
- **内置程序**
  | 程序 | 说明 |
  | --- | --- |
  | 我的电脑 | 用“硬盘容量条”展示技能 |
  | 关于我 | 个人简介、技能、联系方式 |
  | 我的文章 | 博客文章列表（平铺/详细信息视图、搜索），双击用“写字板”阅读 |
  | 我的项目 | 项目列表，双击打开项目主页 |
  | Internet Explorer | 以 2005 年风格博客页面浏览文章，支持前进/后退、标签、搜索、404 页 |
  | 记事本 | 可编辑、自动换行、另存为 .txt |
  | 扫雷 | 三种难度、计时、英雄榜（本地记录）、首击必安全、手机长按插旗 |
  | 画图 | 铅笔、刷子、橡皮、油漆桶、取色、喷枪、直线、矩形、椭圆，撤销/重做，保存 PNG |
  | 命令提示符 | `help`、`dir`、`blog`、`read 1`、`color 0a`、`ping`…… |
  | 回收站 | 可以清空（里面装着“烦恼”和“拖延症”） |
  | 显示 属性 | 更换壁纸、设置屏幕保护程序（飞越星空 / 变幻线 / 字幕） |
  | 运行 | 输入 `winmine`、`mspaint`、`notepad`、`cmd`、`iexplore` 等 |
- **手机适配**：小屏幕上窗口自动最大化，轻点图标即可打开

## 本地预览

任意静态服务器即可，例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 直接双击 `index.html` 也能运行。地址后加 `?skip` 可以跳过开机动画。

## 修改内容

所有个人信息都集中在 **`js/data.js`**：

- `owner`：名字、头衔、头像、简介、技能（`level` 0–100）、联系方式
- `posts`：博客文章，正文使用 Markdown（支持标题、列表、引用、表格、代码块、链接、图片）
- `projects`：“我的项目”文件夹里的条目
- `links`：IE 收藏夹 / 友情链接
- `systemName`：开机画面和各处显示的系统名

头像可以替换 `assets/avatar.svg`，或者把 `owner.avatar` 改成你自己的图片路径。

## 部署到 GitHub Pages

1. 打开仓库的 **Settings → Pages**
2. *Build and deployment* 选择 **Deploy from a branch**，选中存放代码的分支和 `/ (root)` 目录
3. 保存后稍等片刻，访问 `https://<用户名>.github.io/blog/`

## 目录结构

```
index.html            页面骨架（开机、登录、桌面、任务栏）
css/xp.css            Luna 主题样式
js/data.js            网站内容配置 ← 改这里
js/core.js            工具函数、Markdown 渲染、菜单、消息框
js/wm.js              窗口管理器与任务栏按钮
js/shell.js           开机/登录/关机、桌面图标、开始菜单、通知区域
js/apps/*.js          各个程序
assets/icons/         SVG 图标
assets/wallpapers/    SVG 壁纸
```
